Stabilizer board

General (non-CSS) stabilizer codes, verified and ranked apart from the CSS board. Back to the CSS board.

CSS boardFAQResearch logReferencesGitHub

A general stabilizer code has one binary symplectic check matrix S = (A | B): generator i acts as X on Ai and Z on Bi, Y where both. A CSS code is the special case where every row is pure X or pure Z; here every code has at least one mixed generator (a code that is CSS up to a Hadamard on some qubits is filed as a duplicate of its CSS image, not listed twice). These codes are ranked on their own board because the quantities the CSS board reads per side have no side here:

Symplectic doubling maps any [[n, k, d]] stabilizer code to a CSS code [[2n, 2k, d′]] with d ≤ d′ ≤ 2d, so the two boards are linked; halving that map is how the highest-rate entries here were built. See the schema, tracks, and how to submit a stabilizer code (bring S, or A and B, as an .npz).

Primary tracks

Computed grid of locality × check weight, derived from H and the layout, not self-declared. Each cell lists its Pareto frontier, ranked by the selected score (kd²/n, or geometric efficiency g for codes with a verified layout); codes tied on the score rank by the lowest (n, k) pair. The code count filters the table below to that cell. Membership nests: a tighter cell’s codes also compete in the looser ones. In the g view, the seeded surface/toric tilings are not raced; they set the ceiling g is normalized to (surface code = 1) and appear dimmed below the ranking.
