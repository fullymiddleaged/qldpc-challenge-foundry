## Exact reduction

In the source numbering, take X row 0

```text
S = {0, 3, 34, 48, 258, 275, 288, 307}
```

and choose `a = 0`. The only other X generator meeting `a` is source row
169, with support `{0,259}`. Replace it by its sum with `S`, so that `a`
occurs only in `S`. Apply the CNOT fan-out from control 0 to targets
`{3,34,48,258,275,288,307}`. On the binary check matrices this is

```text
H_X[:, b] ^= H_X[:, 0]   for b in {3,34,48,258,275,288,307}
H_Z[:, 0] ^= H_Z[:, b]   for b in {3,34,48,258,275,288,307}.
```

The first operation maps `S` to the weight-one stabilizer `X_0`. The
second maps column 0 of `H_Z` to the parity over `S`, which is zero for
every Z row by CSS commutation. Qubit 0 is therefore disentangled. Delete
`X_0` and qubit 0, and map each surviving source index `q > 0` to
`q - 1`.

This is a Clifford equivalence followed by removal of a stabilized product
qubit, hence `k` remains 18. Every surviving qubit keeps its source
coordinate. The maximum check weight remains 8, the measured interaction
radius remains 4.242640687119285, and the layout remains bilayer.

The transformed source witnesses have X weight 20 and Z weight 18 and pass
the kernel and nontriviality checks. The distance claim remains an upper
bound, not an exact-distance certificate.
