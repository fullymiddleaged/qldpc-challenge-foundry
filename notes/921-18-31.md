## Exact reduction

In the source numbering, X row 359 is the weight-two stabilizer

```text
S = {18, 483}.
```

Choose `a = 483`. The two other X generators meeting `a` are source rows 396
and 415. Clear `a` from them by

```text
R_396 <- R_396 + S
R_415 <- R_415 + S.
```

Their supports become `{18,21,64,84,482,504,523,548}` and
`{18,42,62,501,526}`, respectively. Apply the CNOT with control 483 and
target 18. On the binary check matrices this is

```text
H_X[:, 18]  ^= H_X[:, 483]
H_Z[:, 483] ^= H_Z[:, 18].
```

The first operation maps `S` to the weight-one stabilizer `X_483`. The second
maps column 483 of `H_Z` to the parity over `S`, which is zero for every Z row
by CSS commutation. In the explicit source matrix, Z row 18 is the only Z row
meeting qubit 483 and it contains both 18 and 483, so the column clears
directly. Qubit 483 is therefore disentangled. Delete `X_483` and qubit 483,
and map each surviving source index `q > 483` to `q - 1`.

This is a Clifford equivalence followed by removal of a stabilized product
qubit, hence `k` remains 18. Every surviving qubit keeps its source
coordinate. The maximum check weight remains 8, the measured interaction
radius remains 4.242640687119285, and the layout remains bilayer.

The transformed source witnesses both have weight 31 and pass the kernel and
nontriviality checks. The distance claim remains an upper bound, not an exact
distance certificate.
